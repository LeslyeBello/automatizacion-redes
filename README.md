### Práctica 3. Primer programa de Python para representar información de dispositivos

**Estado:** Completada.

**Integrantes:** Juan Acevedo, Leslye Bello, Genesis Conde y Ehulises Araiza.

**Grupo:** 3IRI2V.

**Propósito:** Desarrollar un programa en Python para organizar y representar la información de los routers y switches configurados en la Práctica 2, como preparación para la automatización de redes.

**Actividades realizadas:**

- Se representaron los dispositivos de red mediante listas y diccionarios.
- Se utilizaron ciclos `for` para recorrer la información de los dispositivos.
- Se implementaron estructuras `if` para revisar el estado de los equipos.
- Se utilizaron funciones para organizar y reutilizar el código.
- Se representaron los dispositivos R1, R2 y S1 con sus direcciones IP, estado y funciones.
- Se realizaron pruebas para mostrar los dispositivos, verificar sus datos y evaluar sus estados.

**Conclusión:** Se comprendió la utilidad de las estructuras de datos de Python para organizar la información de una red. Este programa sirve como base para futuras prácticas en las que se buscará obtener información de los dispositivos mediante herramientas de automatización.
