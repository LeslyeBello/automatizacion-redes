# Recursos de Python

## ¿Qué es la documentación oficial de un lenguaje de programación?

Es la información publicada por los responsables de un lenguaje de programación. Sirve para aprender cómo funciona y cómo utilizar sus instrucciones correctamente.

## ¿Qué información se puede encontrar?

Se pueden encontrar explicaciones, ejemplos, funciones, tipos de datos, instrucciones y recomendaciones para utilizar el lenguaje. 

## ¿Cómo ayuda a resolver dudas?

Permite consultar cómo funcionan las variables, listas, diccionarios, ciclos y funciones. También ayuda a identificar errores y conocer la forma correcta de utilizar las instrucciones.

## Diferencia entre documentación oficial y un foro

La documentación oficial explica cómo funciona el lenguaje y presenta información de referencia. En un foro, diferentes personas comparten preguntas, experiencias y posibles soluciones a problemas específicos. En ambos casos es importante comprobar que la información sea adecuada.
